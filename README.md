# auto-spotify-s
Test Automation Framework for Spotify Website with Selenium.

## 🚫 Web API Restrictions

Due to Spotify platform limitations, this project has the following restriction:

- The Spotify Web API is **not accessible for free-tier accounts**.
- All applications are blocked from accessing certain Web API endpoints without a **Spotify Premium subscription**.
- To use features such as playback control or user-specific data, **Spotify Premium** account is required.

> ⚠️ If you encounter authorization or playback-related errors, ensure your account has an active Premium subscription.
